# Desarrollo del proyecto 

El proyecto PECOTA fue desarrollado por Nate Silver con el objetivo de predecir el rendimiento futuro de jugadores de béisbol utilizando datos El proyecto PECOTA fue desarrollado por Nate Silver con el objetivo de predecir el rendimiento futuro de jugadores de béisbol utilizando datos históricos y métodos estadísticos. 

PECOTA analiza la información de los jugadores, como su edad, rendimiento, estadísticas defensivas y ofensivas y compara con jugadores con características similares.
A partir de esos datos, el sistema genera proyecciones del comportamiento que tendría cada jugar en la temporada.

Este proyecto se relaciona directamente con la ciencia de datos porque incluye una recolección, organización, análisis, construcción de modelos e interpretación de los datos.
La importancia de PECOTA es demostrar que los datos pueden ayudar a tomar decisiones mas informadas.
